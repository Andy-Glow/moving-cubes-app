# Интерактивная площадка «Управление кубиками» 

Приложение представляет собой интерактивную 2D-песочницу для взаимодействия с объектами в замкнутом пространстве.

**Ссылка на живой проект:** [https://andy-glow.github.io/moving-cubes-app/](https://andy-glow.github.io/moving-cubes-app/)

## Стек технологий

- **React 18** (Декларативный UI)
- **Vite** (Сверхбыстрая сборка и HMR)
- **TypeScript** (Строгая типизация интерфейсов и пропсов)
- **SCSS / Sass Embedded** (Компонентные стили, переменные, вложенность)
- **GitHub Actions** (Настроенный CI/CD автодеплой при каждом коммите)

## Реализованный функционал & Фичи

1. **Игровая площадка 800x800:** Ограниченное валидированное пространство для маневров.
2. **Кастомный Drag & Drop:** Перетаскивание реализовано на чистом JavaScript API (`onMouseDown`, `onMouseMove`, `onMouseUp`) без использования сторонних тяжелых библиотек (показ глубокого понимания работы событий браузера).
3. **Физический движок коллизий (AABB):** Исключено любое наслоение кубиков друг на друга. При резком перемещении мыши движок рассчитывает глубину проникновения и выталкивает кубик ровно на внешнюю грань соседа, превращая его в "твердое тело".
4. **Магнитное прилипание:** При сближении граней кубиков менее чем на 20px происходит автоматическое примагничивание ребро к ребру.
5. **Совместное перемещение:** Сцепленные кубики начинают двигаться единой монолитной группой, учитывая общие габариты для ограничения краями площадки.
6. **Динамический UI:** Возможность перекраски выделенного кубика. Кнопка «Разъединить» плавно раскидывает кубики в случайные координаты с использованием временных transition-флагов (чтобы анимация не мешала отзывчивости Drag & Drop).

## Архитектура проекта

Проект спроектирован по принципам SOLID (в частности, Single Responsibility):

- Логика расчетов мышиных событий и физика коллизий полностью изолированы в кастомном хуке `useDrag.ts`.
- Компоненты разделены на презентационные («глупые») элементы: `Field`, `CubeElement`, `ColorPicker`, `DisconnectButton`.
- Соблюден однонаправленный поток данных (Data Down, Actions Up).
